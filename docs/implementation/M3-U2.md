# M3-U2 — Manual Quote Entry Vertical Slice

## Status

`COMMITTED`

The human authorized implementation of the approved plan. This unit follows the Full Flow.

## Objective

Allow a user to create, review, edit, and explicitly confirm a manual quote for a shortlisted supplier.

## Dependencies

M3-U1 is committed at `6a69e62`. Its persistence models and provenance rules are available.

## Approved implementation plan

1. Add session-scoped manual quote list, create, read, draft PATCH, and confirm endpoints. Creation and confirmation require the Quotes stage and a currently shortlisted supplier. A duplicate quote conflicts.
2. On creation, persist every normalized field; omitted keys and explicit null both mean Unknown. On draft PATCH, omitted keys are unchanged, explicit null means Unknown, and explicit null notes clear notes. Manual values have USER_ENTERED origin and no AI or PDF evidence.
3. Add a Quotes workspace for shortlisted suppliers with manual form, draft review and editing, and explicit confirmation. All-unknown confirmation is allowed. Confirmed quotes cannot be edited in this unit.
4. Initial confirmation keeps revision zero and sets confirmed_at. M3-U9 revision, staleness, and retry behavior is excluded.

## Acceptance criteria

- A shortlisted supplier's manual quote can be created, reviewed, edited while in NEEDS_REVIEW, and confirmed by the user.
- Unknown and omitted normalized fields behave as specified; confirmed quotes are authoritative and cannot be edited.
- Unshortlisted and foreign-session access is rejected.
