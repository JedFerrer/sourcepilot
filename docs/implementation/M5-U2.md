## Approved implementation plan

### Deterministic workflow summary

Add a typed, read-only summary containing `current_stage`, singular `next_action: { code, reason_code, target_stage }`, shortlist count, eligible confirmed-quote count, comparison readiness/presence/freshness, supplier freshness, and stage prerequisite reason codes.

Use the following ordered, first-match decision table. Each project receives exactly one next action. Anchors attach to existing controls or their immediate control groups; following a link never executes the action.

| First matching condition | Stage | Action code | Reason code | Existing-control anchor |
|---|---|---|---|---|
| Brief unapproved and existing `can_analyze` is true | Brief | `ANALYZE_BRIEF` | `BRIEF_ANALYSIS_AVAILABLE` | `#brief-analyze`: Analyze request |
| Brief unapproved and readiness is incomplete | Brief | `COMPLETE_BRIEF` | `BRIEF_INCOMPLETE` | `#brief-complete`: editor and Save Brief |
| Brief unapproved and ready for review | Brief | `APPROVE_BRIEF` | `BRIEF_APPROVAL_REQUIRED` | `#brief-approve`: Approve Brief |
| Approved Brief, no candidates | Suppliers | `DISCOVER_SUPPLIERS` | `SUPPLIERS_NOT_DISCOVERED` | `#supplier-discover`: Discover Suppliers |
| Existing M2 freshness result reports stale evaluations | Suppliers | `REFRESH_SUPPLIERS` | `SUPPLIER_EVALUATIONS_STALE` | `#supplier-discover`: Re-discover and re-evaluate |
| Shortlist unapproved with zero selected suppliers | Suppliers | `REVIEW_SHORTLIST` | `SHORTLIST_EMPTY` | `#shortlist-review`: shortlist controls |
| Shortlist unapproved with more than three selected suppliers | Suppliers | `REVIEW_SHORTLIST` | `SHORTLIST_OVER_LIMIT` | `#shortlist-review`: shortlist controls |
