## Dependencies

None.

## Approved scope

- pnpm workspace with `apps/web` and `apps/api`.
- Next.js/React/TypeScript web shell with a visible health state.
- FastAPI `GET /health` endpoint returning `{"status":"ok"}`.
- Same-origin proxy: browser `/api/health` maps to FastAPI `/health`.
- Docker Compose PostgreSQL service with a `pg_isready` health check.
- Local configuration examples and focused local-development instructions.
- Vitest + React Testing Library health-state tests, pytest health smoke test, lint/typecheck/build commands, and CI smoke workflow.

## Explicitly out of scope

- SQLAlchemy, migrations, DB sessions, persistence code, application database connectivity, or application database settings.
- Anonymous sessions, project/domain behavior, AI infrastructure, supplier/quote/comparison/decision behavior, evals, and reusable frontend API client.
- Root application README, application containers, browser E2E, and all later implementation units.

## Approved implementation plan

1. Establish the workspace, web/API project manifests, local configuration examples, and Compose PostgreSQL service.
2. Implement the minimal FastAPI health endpoint and the Next.js shell that requests the explicit proxy contract.
3. Add only M0-U1 smoke and UI-state coverage plus automated local/CI commands.
4. Verify PostgreSQL through Compose health and `pg_isready`; do not wire it into the application.
