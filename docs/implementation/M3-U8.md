## Objective

Persist validated PDF extraction evidence and expose the PDF source, AI extraction, and current draft value separately. Allow correction while a PDF quote is `NEEDS_REVIEW` without confirming it.

## Approved implementation plan

1. Add `QuoteFieldEvidence` linked to `QuoteValue` and `DocumentBlock`, with optional `evidence_value`. During the existing successful background transaction, resolve U6 source IDs only against already validated, persisted blocks of the current quote's `QuoteDocument`. Reject missing or cross-document blocks and roll back the entire draft. Store known-field associations and every conflict alternative with its citations, without selecting a conflict value. Do not alter the U6 contract. Its `ConflictAlternative` already provides a value and source block IDs.
2. Extend quote reads to expose `ai_extracted_value`, `current_value`, `current_origin`, and `uncertainty` separately from evidence entries containing `block_id`, `page`, `block_text`, and `evidence_value`. Show each conflict alternative with its own citations. The block text is the PDF source; `evidence_value` is an associated extracted interpretation. Older U7 drafts without associations report evidence unavailable rather than inventing it.
3. Extend `PATCH /quotes/{quote_id}` for PDF quotes only in `NEEDS_REVIEW`, preserving owner, stage, shortlist, and field validation. For each explicitly patched field, compare the normalized submitted value to `ai_extracted_value`: exact equality sets `AI_EXTRACTED`; every other value, including clearing a known value or filling an unknown value, sets `USER_CORRECTED`. Unmentioned fields remain unchanged. PATCH may update current values and notes, but never evidence associations, extracted values, or uncertainty. Preserve manual editing and reject edits in other PDF states.
4. Show all PDF draft fields, Unknown and Conflict states, uncertainty, source page/block text, AI value, current value, and origin. Add edit, clear, save, cancel, and error states. Keep Processing and Failed displays. Add no PDF confirmation or retry controls.

## Acceptance criteria and tests

- Provenance tests cover sourced known fields, clear, fill unknown, restore extracted, conflict with null current and cited alternatives, cross-document rejection and atomic rollback, and unchanged evidence after PATCH.
- API tests cover owner isolation, invalid fields, disallowed states, and older drafts without associations. Frontend tests cover distinct source/AI/current labels, conflict citations, correction, cancellation, and save failures.
- Run relevant backend and frontend suites, the existing extraction evals, migration checks, type checks, and lint. Perform Browser QA for PDF review and correction in its later Full Flow stage.

## Explicitly out of scope

PDF confirmation, `quote_revision` changes, stale-processing detection, retry, reprocessing, failed-PDF manual fallback, U6 contract changes, new infrastructure or dependencies, and generalized evidence management. The current 21 fields are not a schema invariant.

## Implementation results

Implemented on 2026-09-27. The new `QuoteFieldEvidence` table stores document-block associations and optional extracted interpretations. The PDF worker resolves every U6 citation against persisted blocks belonging to its own document inside the existing finalization transaction; missing or cross-document citations reject the draft. Conflict alternatives retain their values and separate citations without changing the U6 contract or selecting a current value.

Quote reads now separate raw block ID/page/text and associated `evidence_value` from AI extraction, uncertainty, current value, and origin. PDF PATCH accepts only `NEEDS_REVIEW` drafts, changes current values and notes only, and chooses `AI_EXTRACTED` on exact normalized restoration or `USER_CORRECTED` otherwise. The Quotes page shows source citations, unknowns, conflicts, current values, and draft correction controls. Older U7 drafts without associations show no saved citations.
