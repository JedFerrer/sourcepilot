## Objective

Create a reproducible, explicitly synthetic PDF quote corpus for the
existing M3-U4 text-block parser.

## Source-of-truth references

- Product Specification v0.2: §§23–31 and quote failure/recovery flows.
- Technical Architecture v0.2: §§13.5, 14.1–14.5, 17.6, and 27.6.

## Dependencies

M3-U4 is committed. Its bounded PyMuPDF parser extracts ordered text
blocks with stable page/block references and rejects image-only PDFs.

## Approved implementation plan

1. Add three primary, fictional supplier quote PDFs for Harbor Pouch
   Works, Willow Stitch Studio, and Moss Thread Bags. Each quotes 2,000
   units in USD. Harbor has slightly higher pricing, acceptable
   production lead time, and the strongest stated evidence. Willow has
   the lowest price, slower production, and no preferred certification
   stated. Moss has the fastest production and higher tooling cost.
   Moss's sample lead time is explicitly unstated; its shipping cost
   and shipping time are stated.
2. Add a missing-shipping quote variant with shipping cost and time
   absent, a quote variant with contradictory production lead times,
   and an image-only unsupported PDF. Mark every fixture visibly as
   synthetic and describe the corpus alongside the files.
3. Use the existing PyMuPDF dependency to create the PDFs. Commit the
   resulting files and version parser-only expected page numbers,
   block references, and exact text. Add no dependency.
4. Add fixture tests using the M3-U4 parser. Assert expected blocks,
   repeatability, the meaningful missing/conflicting text, and the
   image-only failure.

## Acceptance criteria

- Six versioned PDFs cover the three primary and three additional cases.
- All fixtures are explicitly synthetic; the primary three use USD
  and show the specified commercial tradeoffs.
- Moss's unknown sample lead time is distinct from the separate
  missing-shipping case.
- Text PDFs produce the versioned parser output; the image-only PDF
  raises `NoExtractableTextError`.

## Implementation results

Implemented on 2026-09-27. Six repository-owned synthetic PDFs now cover the
three primary offers, missing shipping, contradictory production lead times,
and an image-only document. The primary quotes each price 2,000 units in USD.
Moss explicitly leaves sample lead time unstated while providing both shipping
cost and shipping time. The missing-shipping variant retains a stated sample
lead time but omits shipping cost and time. The five text PDFs have versioned
parser-only page counts, block references, and exact text; the image-only PDF
has a visible synthetic notice as raster content and no text layer. The
generator uses the already locked PyMuPDF and its reproducible-save option;
two consecutive generations produced identical SHA-256 hashes for all six
files. No dependency, extraction contract, AI eval, processing path, API,
database, or UI change was added.

The new fixture tests and existing M3-U4 parser tests passed together:
**27 passed**. Ruff passed, Pyright reported **0 errors and 0 warnings**,
and the lockfile check passed. All primary pages, Harbor's supporting page,
the missing-shipping page, the conflicting schedule page, and the image-only
page were rendered and inspected for legibility and clipping. Browser QA is
not applicable because this unit adds no browser-visible behavior. AI evals
are not applicable because this unit adds no AI behavior. The unit is
