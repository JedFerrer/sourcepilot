## Approved scope and implementation plan

1. Define a strict `QuoteExtraction` contract covering the existing quote field keys. Each field has state `KNOWN`, `UNKNOWN`, or `CONFLICT`, a candidate value or null, source block IDs, uncertainty, and conflict alternatives. `KNOWN` requires a value and supporting IDs; `UNKNOWN` requires null; `CONFLICT` requires null as the primary value and at least two distinct alternatives, each with supporting IDs. For a conflict, field source IDs equal the union of alternative IDs. Validate every returned ID against the current document's blocks.
2. Add prompt v1 and an application service that checks active demo-session ownership, loads persisted numbered blocks, and invokes the existing structured model client with no tools. Treat document content solely as untrusted data.
3. Reuse the structured runner for schema validation, one repair retry, provider recovery, and AIRun tracing. On failure return no draft and preserve the original PDF, blocks, quote, and document.
4. Add versioned extraction expectations and recorded outputs for the three primary PDFs, missing shipping, and conflicting lead time. Score field, numeric, currency, unknown, conflict, source-reference, and invented-value errors. Image-only PDF fails during parsing without a model call. Live evals are opt-in.

## Acceptance criteria

- Primary PDFs yield expected typed draft fields with valid source references.
- Missing information remains unknown. Conflicts expose alternatives without choosing a primary value and cite all relevant blocks.
- Invalid, absent, or cross-document references fail validation and receive only one repair retry.
- Extractor has no tools. Failure leaves source and quote domain state unchanged and records the AIRun outcome.

## Implementation results

Implemented the strict 21-field `QuoteExtraction` contract, prompt v1, and a demo-session-scoped extraction service. The contract preserves `UNKNOWN`, requires null as a conflict's primary value, requires at least two distinct sourced alternatives, and checks the field-level source set against all alternatives. The service checks all returned references against the selected document's persisted blocks. It uses the existing no-tools structured client, one repair retry, provider recovery, and AIRun tracing. It changes no quote values, PDF bytes, blocks, or processing status.

Added five versioned offline extraction cases and recorded outputs using the committed synthetic PDFs. The eval scores field, numeric, currency, unknown, conflict, source-reference, and hallucination behavior. The image-only fixture remains a parser failure. No dependency, migration, endpoint, frontend change, or later-unit processing/review behavior was added.
