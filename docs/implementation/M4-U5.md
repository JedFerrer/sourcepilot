## Proposed implementation plan

1. Extend the immutable `AnalystToolContext` with `permitted_quote_ids: frozenset[UUID]`, defaulting to an empty set after `max_tool_calls` to preserve existing positional and keyword M2 supplier-tool callers. Normalize the set in `__post_init__`. Add typed results for comparison availability (`CURRENT`, `STALE`, `ABSENT`) and quote-field evidence. Keep the existing supplier tool signatures and runtime behavior. Make trace events identify the new no-ID comparison call and the quote/field call without breaking supplier-tool trace consumers. All four tools share the same successful-call budget; errors are traced without consuming it.
2. Add a small read-only project guard for each new call. Revalidate the active demo session and project ownership from persisted state on every invocation, under `no_autoflush`. A denied project returns `NOT_ALLOWED`; no query or error should reveal another session's comparison or quote.
3. Implement `get_comparison_snapshot` for the context's implicit project. Read only its latest generated snapshot. Return `ABSENT` when none exists. For a current snapshot, return the deterministic payload, snapshot identity and input revisions, generated time, and `stale=false`. Compute effective staleness with M4-U3's authoritative read-time rule, including stage, brief revision, active quote IDs/revisions, and fact fingerprints. For a stale snapshot, return `STALE` with snapshot identity, revision metadata, and `stale=true`, but withhold the old comparison payload so it cannot be used as current analysis. Do not regenerate or persist staleness as part of the tool call.
4. Implement `get_quote_evidence(quote_id, field_key)` using both immutable permitted quote and supplier sets. Reject a quote ID outside `permitted_quote_ids` before any quote lookup. Then check that the quote belongs to the current project and to a currently shortlisted, non-dismissed permitted supplier; require a current confirmed quote. Unknown or out-of-scope quote IDs return `NOT_ALLOWED` without an existence signal; a missing field on an authorized quote returns `NOT_FOUND`. Return the quote and field identity/revision, the confirmed `current_value` and `current_origin`, separate `ai_extracted_value` and uncertainty, and ordered PDF citations containing evidence ID, document/block IDs, page and block numbers, source block text, and `evidence_value`. Include only evidence joined to the quote value and that quote's active PDF document. Return an empty citation list for a manual or uncited field, without inventing PDF support. Mark citations as provenance rather than support when a confirmed user correction or unresolved conflict makes the source representation differ from the authoritative value.
5. Keep uploaded block text explicitly typed as untrusted source data in the result contract. The tool must neither execute it nor convert it into instructions. Do not add raw storage access, writes, model prompts, an agent loop, an API route, UI behavior, schema migrations, or dependencies.

## Acceptance criteria

- Comparison reads are session/project scoped and distinguish absent, current, and stale. The latest stale snapshot cannot supply requirement states or quote facts as current analyst input.
- Quote evidence cannot be fetched for a quote outside the runtime's immutable quote allowlist, from another project/session, an unpermitted or no-longer-shortlisted supplier, or a non-confirmed quote. It cannot mix documents, fields, or quotes.
- The quote result labels the confirmed current value and origin separately from AI/source values; correction and conflict provenance remains inspectable. Missing PDF evidence stays explicit.
- Neither tool flushes, commits, mutates ORM state, changes comparison staleness, nor creates an AIRun. Successful calls consume the existing shared budget and every outcome is traced.

## Risks and boundaries

- Reusing ORM-loaded objects in a dirty caller session can accidentally expose pending edits or flush them. The implementation must read persisted state while preserving pending edits, as M2-U5's tool regression requires.
- The existing comparison API can display a stale historical payload; the analyst tool will expose its stale metadata but withhold that payload. This does not change the UI or persisted snapshot.
- PDF block text is untrusted evidence data. Its presence in a result must never grant it instruction authority in M4-U6's later model use.
- Tradeoff generation, suggested supplier behavior, prompt/agent orchestration, and browser-visible changes belong to later units.
