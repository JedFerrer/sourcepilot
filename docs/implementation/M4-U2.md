## Approved scope and plan

1. Add a pure comparison-domain evaluator with only `MEETS`, `DOES_NOT_MEET`, `UNKNOWN`, and `CONFLICT`. Reuse material, certification, MOQ, and capability checks; keep subjective unsupported requirements informational. Preserve source references and evidence attribution.
2. Return typed warning metadata separately from states. Define deterministic conditions for different quote currencies, a quote currency differing from an explicit target currency, missing currency needed for price evaluation, and a quoted quantity mismatch. M4-U3 assembles warnings into a snapshot.
3. Compare confirmed quoted quantity to approved requested quantity. An exact match meets; mismatch does not meet and warns; absence and source conflict yield `UNKNOWN` and `CONFLICT`.
4. Compare decimal unit prices only when quoted quantity aligns and currencies are directly comparable. `Requirement.expected_value` can persist an optional explicit `currency`; `Brief.target_unit_price` persists only an amount. Without an explicit persisted target currency, price evaluation is `UNKNOWN`. This data-model gap is upstream; do not infer or default currency, convert currencies, or add a migration.
5. Parse only clear single day counts and day ranges for production lead time. A range meets when its latest day fits the maximum, fails when its earliest day exceeds it, and otherwise is `UNKNOWN`.
6. Complete delivery compatibility at the domain-contract level from an explicit confirmed dated commitment: on or before a target date or within a dated target period is `MEETS`, after it is `DOES_NOT_MEET`, absent is `UNKNOWN`, and source conflict is `CONFLICT`. Before a period's start or without its end date is `UNKNOWN`. The current quote adapter supplies no dated commitment, so current persisted quote data evaluates as `UNKNOWN`. Do not infer an order date or derive a date from lead-time text.
7. Extend the M4-U1 fact adapter only for confirmed quoted quantity and evaluator inputs. Add no persistence/schema changes, API, UI, AI behavior, dependencies, or M4-U3 integration.
